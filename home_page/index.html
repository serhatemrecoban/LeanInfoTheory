What is new in v0.2.0

Current source contains 811 supported declarations across 57 modules, with 92 lightweight-root exports. The release adds finite total variation and coupling, Pinsker and continuity, product laws, finite iid AEP, fixed-length source coding, attained finite information capacity, and channel-coding weak converses.

These results retain explicit finite-alphabet, support and independence hypotheses. Channel-coding achievability and a channel strong converse remain outside this release. See the current import guide, capabilities and limits, and Perfect Functional Representations case study.

A foundation for your next formalization

Put machine-checked information theory to work. LeanInfoTheory is a reusable Lean 4 and mathlib library for finite discrete information theory, bringing entropy, mutual information, KL divergence, channels, Markov chains, data processing, Fano inequalities, and sufficient statistics into one substantial mathematical toolkit.

Build research formalizations and information-theoretic software on proved foundations. Install the tagged release, choose a focused import, and reuse the results in your own proofs. Every formal theorem is checked by Lean against its stated assumptions; the maintained release validation rejects proof placeholders.

Install and prove your first result or explore the research-project guide.

Validation and Trust

Release declarations are checked by Lean's kernel and the maintained project builds. Continuous integration also regenerates the source-derived references and rejects proof placeholders in project Lean source.

Kernel checking establishes that formal declarations follow from their formal assumptions; theorem selection, assumptions, conventions, and mathematical interpretation remain human responsibilities.

Project Direction

The second release brings quantitative probability, independent products, finite-iid source coding and channel capacity into the library's finite information-theory framework. The original v0.1.0 API and historical archive remain available unchanged.

  • Implemented Total variation, maximal coupling, Pinsker bounds, continuity and finite probability topology.
  • Implemented Independent products, iid blocks and product-channel bounds for arbitrary inputs, with equality for independent inputs.
  • Implemented Finite-iid asymptotic equipartition, fixed-length source coding above entropy, and source-coding converses.
  • Implemented Attained information capacity, standard finite-channel examples and Fano-based channel weak converses.
  • Case study Perfect Functional Representations demonstrates reuse of unchanged v0.1.0 in a completed downstream formalization.
  • Planned Theorem-level blueprint pages and a blueprint PDF extending the current module dependency map.
  • Later Channel-coding achievability, operational channel-capacity equality and the channel strong converse remain outside this release.
