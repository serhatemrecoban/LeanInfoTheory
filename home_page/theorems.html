Six theorems in v0.3.0

  • Neyman–Pearson. Given finite null and alternative laws and a level between zero and one, choose a threshold and a common tie probability. The resulting randomized test attains that size and has greatest power among all tests of at most that size. Null atoms are allowed. Testing example
  • One-shot channel coding. For a given blocklength, a positive number M of messages and a real threshold t, some supported codebook with a deterministic decoder has uniform-message average error at most the true-pair miss probability plus (M − 1) exp(−t). The mass test applies everywhere. Its log-density interpretation requires joint support. One-shot example
  • Operational capacity. For a finite memoryless channel with nonempty input, information capacity is the least upper bound of achievable rates, including when capacity is zero. For each nonnegative rate strictly below capacity, one code family works for every rate tolerance. Expurgating that family gives vanishing maximal error. Capacity and expurgation example
  • Lossless separation. At one channel use per finite iid source symbol, entropy strictly below capacity gives vanishing block reconstruction error. The converse permits correlated channel inputs and implies entropy at most capacity. These results leave equality open. Separation example
  • Binary prefix length. For iid blocks of positive length n, the minimum expected number of bits per source symbol is at least entropy in bits and strictly less than entropy plus 1/n. The codewords are assigned on the source support. Prefix coding example
  • Type-class probability. For a positive-length empirical law q supported by the prior p, multiply the class cardinality by exp(−n(H(q) + D(q ‖ p))) to obtain the iid probability of the entire class. Entropy and KL are in nats. An observed zero-prior symbol gives zero class mass and infinite KL. Method-of-types example

Results in the published v0.2.0

The v0.2.0 source inventory contains 811 supported declarations across 57 modules. These additions are included in the v0.2.0 reference, with each declaration's exact signature and source.

  • Quantitative finite probability: half-L1 total variation, maximal coupling and gluing, Pinsker, quantitative independence, entropy continuity, and finite-PMF compactness/topology. Null fibers and finite-KL guards remain explicit.
  • Products and AEP: dependent products, iid words, product entropy/KL and actual product-channel information. Finite iid AEP uses supported self-information and strict typical sets; it does not assert a stationary/ergodic extension.
  • Fixed-length source coding: total deterministic codes, integer message budgets, one code family above entropy, a source strong converse and an IsGLB entropy threshold. This does not assert an efficient encoder or attainment exactly at entropy.
  • Finite information capacity: an attained maximizing input law, product/repeated capacity and standard-channel values. The product upper bounds allow correlated channel inputs.
  • Channel weak converses: uniform message indices, possibly colliding encoders and the same actual code throughout Fano, Markov/data processing and capacity bounds. Undivided forms cover zero length; normalized forms retain positive-length/rate guards. Eventual and frequent rate gaps have distinct conclusions.

Information is measured in nats unless explicitly converted. The third release adds direct channel coding and binary prefix coding. A channel strong converse, feedback, cost-constrained channels and infinite alphabets remain outside its scope.

Outside v0.1.0

Canonical/minimal or general measurable sufficiency, exact Fano equality and sharpness, randomized/list decoding, AEP, source/channel coding theorems, and network converse examples are outside that release.
