LeanInfoTheory Blueprint

Project layers and theorem-dependency plan.

This blueprint mixes implemented modules with planned layers. The module-level dependency map is generated from Lean import lines; a source-derived API index is available under documentation; theorem-level blueprint pages, full Lean doc-gen output, and a blueprint PDF remain future work.

Layer 0: Existing foundations

  • mathlib binary and q-ary entropy
  • mathlib KL divergence and KL chain-rule infrastructure
  • mathlib PMFs, finite measures, Markov kernels, and coding foundations
  • PFR-style entropy and mutual-information infrastructure to audit

Layer 1: Finite information measures

  • finite random variables and mathlib PMFs
  • finite Shannon entropy in nats via Real.negMulLog
  • entropy invariance under equivalence, injective alphabet relabeling, swaps, and reassociation
  • finite entropy upper bound by log |alphabet| and the uniform-law equality case
  • joint entropy, conditional entropy, mutual information, and conditional mutual information
  • dependent finite-family laws, finite-atom entropy/MI/CMI, pair/triple compatibility, and binary/ordered entropy, MI, and conditional-MI chain rules
  • finite-selector PMF mixtures and entropy concavity, including the binary interior-weight equality case
  • zero-safe finite log-sum inequality and active-ratio equality with guarded Real corollaries
  • finite-selector KL joint convexity, binary KL equality, and mutual-information input-law concavity and channel convexity
  • common-base channel conditional KL with finite weighted semantics, a joint KL chain rule, and support-guarded Real forms
  • finite-atom mutual independence with restriction/pair laws and n-way entropy-additivity equality characterizations
  • marginal mass formulas, support/domination lemmas, and coordinate-orientation lemmas
  • semantic bridge theorem identifying entropy with expected self-information over PMF.toMeasure
  • finite conditional laws with explicit zero-mass conventions
  • conditional entropy as expected entropy of conditional fibers
  • mutual information as KL divergence from the joint law to the product of marginals
  • conditional mutual information as averaged fiber mutual information and averaged fiber KL
  • semantic nonnegativity of mutual information and conditional mutual information
  • first mutual-information chain rule I(A;B,C) = I(A;C) + I(A;B|C)

Layer 2: Algebraic entropy expressions

  • entropy atoms indexed by finite sets of variable names
  • rational linear combinations of atoms
  • semantic evaluation into real entropy values
  • abstract Shannon entropy valuations for certificate soundness
  • concrete finite-family entropy valuations satisfying the abstract Shannon contract
  • primitive Shannon inequality expressions and valuation soundness theorems

Layer 3: Certificates

  • current nonnegative-combination soundness skeleton
  • current raw/checked certificate split with nonnegative rational coefficients
  • current exact rational expression matching for checked decompositions
  • current basic raw-to-checked validation for primitive-tagged steps
  • current entropy submodularity demo from a validated CMI certificate
  • current opt-in adapter from checked-certificate soundness to concrete finite-family Shannon entropy
  • current homogeneous and dependent-alphabet examples exercising checked and raw certificate paths
  • current checker validates normalized entropy-expression equality; it does not search for certificates automatically
  • future import support for external certificate formats
  • future import path for PSITIP/oXitip-style certificates

Layer 4: Network information theory

  • future data-processing examples
  • future network-converse examples that consume the current finite Fano API
  • future cut-set and multi-terminal converse examples
