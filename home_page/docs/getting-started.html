Getting Started

LeanInfoTheory: information theory in Lean 4.

Install v0.3.0 to prove the entropy example below. The same dependency supports the six testing and coding examples.

Install the stable release

Version 0.3.0 uses Lean and mathlib v4.33.1. You need Elan, Lake and Git. Open a Lean project or create one using lake new MyProject, then open its directory.

Set your project's lean-toolchain to:

leanprover/lean4:v4.33.1

Add this dependency to lakefile.toml:

[[require]]
name = "LeanInfoTheory"
git = "https://github.com/serhatemrecoban/LeanInfoTheory"
rev = "v0.3.0"

From your project directory, resolve dependencies, retrieve the mathlib cache, and build:

lake update
lake exe cache get
lake build

The library fixes its toolchain. Keep the resolved lake-manifest.json with your project so another user can reproduce the same dependencies.

Working from source

For local development, point Lake to a checkout. Replace the tagged dependency above with this entry and adjust its path relative to your project's lakefile.toml.

[[require]]
name = "LeanInfoTheory"
path = "../LeanInfoTheory"

Run the three Lake commands above from your consumer project. Record the source revision with git rev-parse HEAD in the library checkout, together with any local changes.

See the focused import guide and development guide.

Prove your first result

A deterministic law has zero entropy. This is a complete Lean example:

import LeanInfoTheory

open LeanInfoTheory.Shannon

example : entropy (PMF.pure false) = 0 := by
  exact entropy_pure false

Put the example in a Lean file in your project and check it with your editor or lake env lean YourFile.lean. The library supplies the theorem; your proof applies it to the law concentrated at false.

Choose an import

import LeanInfoTheory gives you the lightweight PMF and elementary information-measure layer. import LeanInfoTheory.Shannon loads the complete supported mathematical stack. For a smaller dependency closure, use the focused module guide.

Try the six new packages

Each example includes its focused import and the Lean statement to check in your project.

  • Finite hypothesis testing and Neyman–Pearson constructs an exact-size randomized test.
  • Information density and one-shot coding bounds decoding error at a chosen blocklength and message count.
  • Operational channel capacity and expurgation relates vanishing error to achievable rates.
  • Lossless source–channel separation gives reliable transmission when entropy is strictly below capacity.
  • Binary prefix coding bounds the optimal expected number of bits per source symbol.
  • The method of types computes the probability of an empirical type class.
