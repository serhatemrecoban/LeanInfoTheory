Spend your formalization effort on the new mathematics. LeanInfoTheory supplies reusable information-theoretic foundations for research projects and downstream software.

Start with a dependency, not a copy

Create a separate Lean project and depend on v0.2.0 through Lake. Keep the resolved manifest and toolchain under version control. A later library upgrade should be deliberate, followed by a full build of your own project.

Map paper statements to existing results

  1. List the paper's definitions, theorem statements, and assumptions. Distinguish the target manuscript from supplementary proof sources.
  2. Match basic identities and inequalities to the theorem highlights and release API, then verify candidate names in a compiling Lean file.
  3. Keep paper-specific structures and constructions in your project. Propose a library addition when a missing result is independently useful.
  4. Build one coherent theorem step at a time, including concrete and degenerate examples. Independently review statements as well as proof completion.

Check the mathematical contract

  • Alphabet scope: the release targets finite discrete information theory, not general continuous entropy.
  • Units: canonical quantities use nats; convert explicitly if the paper uses bits.
  • Support: distinguish global assumptions from properties needed only on positive-probability events.
  • Conditioning: track argument order and null fibers; a total conditional law's fallback is not evidence about a probability-zero event.
  • KL: keep infinity and real-valued conversion separate.

What the release provides

Entropy and information identities, finite-family algebra, independence and Markov characterizations, stochastic data processing, finite Fano inequalities, convexity, and sufficiency are available now.

New in v0.2.0

Version v0.2.0 adds finite total variation/coupling, continuity and topology, products, iid AEP, fixed-length source coding, attained information capacity and channel weak converses. Its source inventory has 811 declarations across 57 supported modules. Consult the exact capability limits and current imports; channel achievability, operational channel-capacity equality and a channel strong converse remain outside this release.

Applications and collaboration

Keep paper-specific constructions and application automation in separate projects, with a pinned LeanInfoTheory version supplying the reusable mathematical foundations.

Case study: Perfect Functional Representations

PerfectFunctionalRepresentationsLean formalizes the definitions and main results of On Perfect Functional Representations, within its documented finite-alphabet, support and auxiliary-variable qualifications. It was completed using unchanged LeanInfoTheory v0.1.0, with paper-specific constructions kept downstream. It demonstrates historical library reuse.

This separation provides a useful pattern for research formalization: reuse the library's information measures and channel foundations, and develop the paper's specialized constructions in its own project. Record the dependency version so the formalization can be reproduced independently of later library releases.
