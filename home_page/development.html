Build

git clone https://github.com/serhatemrecoban/LeanInfoTheory.git
cd LeanInfoTheory
lake exe cache get
lake build LeanInfoTheory

The repository currently uses Lean v4.30.0 and mathlib v4.30.0.

Focused Checks

lake build LeanInfoTheory.Shannon.SemanticBridge
lake build LeanInfoTheory.Certificate.Submodularity
lake build LeanInfoTheory.Examples

Website Generation

python scripts/generate_website_blueprint.py
python scripts/generate_website_api_index.py
python scripts/check_website.py

Run these after changing Lean imports, public declarations, or doc comments. They regenerate the website's module-level dependency map, source-derived declaration index, and machine-readable module/declaration JSON data. The checker validates generated JSON and local website links. CI checks that the generated files are current.

Project Hygiene

  • The CI build includes a strict placeholder scan for Lean source files.
  • Core finite Shannon files keep imports light.
  • Heavier KL, conditional-law, Markov, and data-processing imports live in the semantic bridge layer.
  • Certificate examples are separately importable so the base finite API stays small.

Import Guide

  • Use LeanInfoTheory.Shannon.Entropy for finite entropy basics.
  • Use LeanInfoTheory.Shannon.InfoMeasures for marginals, conditional entropy, mutual information, and conditional mutual information.
  • Use LeanInfoTheory.Shannon.FiniteFamily for dependent finite-family laws, atom entropy/MI/CMI, pair/triple bridges, and ordered chain rules.
  • Use LeanInfoTheory.Shannon.EntropyBounds when the Jensen-based upper bound or uniform equality theorem is needed.
  • Use LeanInfoTheory.Probability.FiniteMixture for binary NNReal-weighted PMF mixtures and their endpoint laws.
  • Use LeanInfoTheory.Shannon.LogSum for the zero-safe finite log-sum inequality and equality API.
  • Use LeanInfoTheory.Shannon.EntropyConcavity for general-selector or binary entropy concavity.
  • Use LeanInfoTheory.Probability.FiniteChannel for type-generic raw PMF-valued channel constructions and their elementary laws.
  • Use LeanInfoTheory.Shannon.SemanticBridge for expected self-information, conditional-law, KL, independence, Markov, and data-processing theorems.
  • Use LeanInfoTheory.Shannon.SemanticBridge.Markov or LeanInfoTheory.Shannon.SemanticBridge.DataProcessing directly when only one heavy semantic surface is needed.
  • Use LeanInfoTheory.Shannon.SemanticBridge.Convexity directly for finite-selector KL joint convexity, binary KL equality, and MI input-law concavity and channel convexity.
  • Use LeanInfoTheory.Shannon.SemanticBridge.FiniteFamily directly for family Shannon inequalities and concrete entropy valuations.
  • Use LeanInfoTheory.Certificate.FiniteFamily for checked-certificate soundness under concrete family entropy.
  • Use LeanInfoTheory.Examples.FiniteFamily for the maintained homogeneous and dependent-alphabet family examples.
  • Use LeanInfoTheory.Examples.Convexity for maintained non-public Section 2.7 regression consumers.
  • Use LeanInfoTheory.Certificate.Submodularity for the first certificate-backed inequality demo.
