without invented GitHub Actions variables. It cannot authorize deployment.

links are disabled rather than promoted to immutable links. GitHub source mode
must match the exact expected commit. No local result asserts remote availability
of an unpublished SHA. Dependency-link advisories are checked separately for each
route under explicit bounded policies, never a combined count that hides drift.

unchanged. Candidate/current output, stale bodies/docstrings, wrong versions or
