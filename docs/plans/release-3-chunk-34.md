## Contract

Use one channel use per source symbol. The source has law `p : PMF S`, the channel has raw rows `W : X → PMF Y`, and each alphabet has its own universe. Both proposed public statements take `[Fintype S] [Fintype X] [Nonempty X] [Fintype Y]`. The input instances match the arbitrary-prior capacity bound. A source law already witnesses a nonempty source, and any row at an available input witnesses a nonempty output. No additional inhabitant, full-support, positive-entropy or cardinality hypothesis is needed. Entropies and capacity are real and measured in nats.

In the displays only, `Word A n` means `Fin n → A`. The encoder and decoder are total deterministic functions. For a fixed length write `q := PMF.iid p n`, `K := PMF.memorylessChannel W n`, `J := PMF.channelJoint q (fun s => K (E s))`, and `L := PMF.channelJoint (q.map E) K`. The event is exactly `D y ≠ s` under `J`, including its original source coordinate. C33's `sourceChannelErrorProbability p W n E D` is definitionally `decodingErrorProbability J D`. There are no message indices in these contracts. Collisions, unused inputs, arbitrary decisions on null outputs and dependence among the encoded coordinates are allowed.

Propose exactly two declarations in namespace `LeanInfoTheory.Shannon`:

```lean
mul_entropy_le_mul_channelCapacity_add_error
    (p : PMF S) (W : X → PMF Y) (n : ℕ)
    (E : Word S n → Word X n) (D : Word Y n → Word S n) :
    (n : ℝ) * entropy p ≤ (n : ℝ) * channelCapacity W + Real.log 2 +
      sourceChannelErrorProbability p W n E D * (n : ℝ) *
        Real.log (Fintype.card S : ℝ)

entropy_le_channelCapacity_of_tendsto_sourceChannelErrorProbability
    (p : PMF S) (W : X → PMF Y)
    (E : ∀ n : ℕ, Word S n → Word X n)
    (D : ∀ n : ℕ, Word Y n → Word S n)
    (he : Tendsto (fun n => sourceChannelErrorProbability p W n (E n) (D n))
      atTop (nhds 0)) :
    entropy p ≤ channelCapacity W
```

Propose the new focused owner `LeanInfoTheory.Shannon.SourceChannelConverse` with direct imports `LeanInfoTheory.Shannon.SourceChannelCode` and `LeanInfoTheory.Shannon.ProductChannelCapacity`. It owns both public theorems and exports them through the full Shannon umbrella. The finite bound serves individual codes and the limit theorem. Keep the information comparison private, the scalar rewrites local, and both theorems free of simp attributes. Development examples belong in `LeanInfoTheory.Examples.SourceChannelConverse`, outside the supported umbrellas. The constant-channel examples import `LeanInfoTheory.Shannon.StandardChannelCapacity` for `channelCapacity_const`. The biased example uses the law from `LeanInfoTheory.Examples.StochasticChannels`. ## C34.03 — Permanent consumers and separation boundaries

- **C34.03-COLLISION** — Take two iid fair Boolean bits, send the first bit twice over the noiseless Boolean channel and reconstruct by the identity. Under the actual source/output law `J`, the four source words each have mass `1/4`. Words `00,01` produce `00` and `10,11` produce `11`. Verify the projection to `L`, its two atoms of mass `1/2` and the C33 error `1/2` from `01,10`. Apply the public finite bound to this code. Compute `mutualInfo L = Real.log 2` for the actual induced input. Show `mutualInfo J = Real.log 2` and deduce `condEntropy J = Real.log 2` from `entropy_iid` and the first marginal. The output thus retains one of the two source bits. Substituting the product of the two fair input marginals would give `2 * Real.log 2` over the same noiseless channel. Existing development examples give the diagonal/product calculation for reference. Build the C34 check from the actual iid source and encoder using supported laws. [Diagonal-input precedent](../../LeanInfoTheory/Examples/ProductChannelCapacity.lean#L127)
- **C34.03-BIASED** — At length four use the Boolean law `p` with true mass `3/4` from C33 and a constant Boolean channel (for example, every row `PMF.pure false`). For **every** pair of total maps `E,D` at this length, use the public finite bound on C33's exact error to prove `1/2 < sourceChannelErrorProbability p W 4 E D`. From the two source masses and the supported `entropy_bool`, obtain `4 * entropy p - 3 * Real.log 2 = Real.log (32 / 27 : ℝ) > 0`. The concrete entropy calculation in C33's example is private. Use it as a derivation reference. With `channelCapacity_const`, the finite bound reads `4 H(p) ≤ log 2 + 4 Pe log 2`. If `Pe ≤ 1/2`, the right side is at most `3 log 2`, a contradiction. This uses multiplication by the positive `log 2` only. It tests the iid nonuniform source, the coefficient of blocklength in Fano, and a code-independent consequence at a single length. [C33 source calculation](../../LeanInfoTheory/Examples/SourceChannelSeparation.lean#L49)
- **C34.03-IMPOSSIBLE** — Keep the asymptotic caller separate. On a uniform Boolean source and a constant-output Boolean channel, compute `entropy p = Real.log 2 > 0` and `channelCapacity W = 0` using `entropy_uniformOfFintype` and `channelCapacity_const`. For every encoder family and every decoder family, assuming their C33 error tends to zero contradicts the public limit theorem. Exhibit that universal negated limit.
- **C34.03-SINGLETON** — On a one-symbol source prove entropy zero, the word logarithm zero and C33 error exactly zero at every length for arbitrary total maps. Use the mismatch event or sum, since all source words coincide. Feed that error limit into the public converse and obtain `0 ≤ channelCapacity W`, including for the constant channel at capacity zero. Verify length zero also for a nonsingleton source with its unique empty word. A singleton equality example gives no general theorem at equality.
- **C34.03-PACKAGE** — Compile a caller importing only `LeanInfoTheory.Shannon.SourceChannelSeparation` and `LeanInfoTheory.Shannon.SourceChannelConverse`. For the strict lower regime open one pair from C33 and pass its very same error limit to C34. For the strict upper regime rule out a vanishing-error pair with the universal converse. State the two implications separately. Equality, lossy coding, bandwidth expansion and a strong converse are outside this contract.
