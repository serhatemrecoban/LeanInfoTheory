## C29.03 — The total acceptance-event decoder

The conditional request was admitted only after the actual C29.02 closure,
original report/reconciliation and all 369 final source entries, environment
and protected Git state matched. Only Step 3 is selected under approved r2.

### Source and assumptions

`BlockChannelCode.ofAcceptanceEvent b A hM` is the literal released code pair.
Its encoder is definitionally b at the original n and M. For every output y,
filter Finset.univ of message indices by `(b i,y) ∈ A`. A nonempty filtered
set supplies its least member through Finset.min'; an empty one supplies
index zero using hM. Classical membership accepts every set. The construction
needs neither alphabet to be finite and stays total even off channel support.
The private/local set is a proof device, with no public helper or simp rule.

`BlockChannelCode.decoder_ofAcceptanceEvent_eq_of_unique` puts the sent index
in that set. Its minimum therefore passes, so the failure of every other index
forces it to equal the sent index. This proves the approved sufficient success
condition without assigning failure to every unsuccessful test of the sent word.
Typed definitional conversion exposes the branch expression; it avoids creating
constructor equation declarations in a consumer. Both previous pair laws and
all earlier declarations/proofs remain unchanged.
