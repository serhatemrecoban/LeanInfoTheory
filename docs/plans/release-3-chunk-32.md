## Mathematical contract

Fix `c : BlockChannelCode X Y n M`, a raw channel `W : X → PMF Y` and `[Fintype Y]`. Write `row m = PMF.memorylessChannel W n (c.encoder m)`. The sent index `m : Fin M` determines both the row to sample and the label against which the total decoder is judged. Distinct indices can have the same row and different error probabilities. A message with zero prior mass still has a well-defined row error. All error quantities are real probabilities.

For `hM : 1 ≤ M`, let `e = c.errorProbability W hM` and let `G` consist of **all** old indices with row error at most `2*e`. The full retained budget is `L = G.card`. Prove `(M+1)/2 ≤ L` in natural-number arithmetic, enumerate exactly `G`, and use that enumeration for a code of every exact budget `1 ≤ K ≤ L`. At each budget one encoder and one total decoder serve every prior. At positive length the full retained budget satisfies `codeRate n M - Real.log 2 / (n : ℝ) ≤ codeRate n L`. Choosing a smaller budget keeps the reliability guarantee. A rate floor for that budget requires its own size hypothesis.

**Ownership.** Put the finite code API in a new focused `LeanInfoTheory.Shannon.ChannelCodeExpurgation` importing only `LeanInfoTheory.Shannon.ChannelCode`. Put the scalar half-budget rate inequality in the existing `Shannon.CodingRate` owner. Put the transfer for a supplied C31 family in a new `LeanInfoTheory.Shannon.OperationalExpurgation` importing `Shannon.ChannelCodeExpurgation` and `Shannon.CodingRate`. Its assumptions are the components of the witness. Only the C31-facing consumer additionally imports `Shannon.OperationalCapacity` to obtain them from `IsAchievableRate`. Use the full `LeanInfoTheory.Shannon` prefix for these imports. Export each new owner from the full Shannon umbrella. This keeps finite selection available without capacity, random coding, or asymptotic source coding. The proposed growth uses two reviewed new-module records and the corresponding full-umbrella import approvals. Restriction itself uses only a code, an embedding of labels and a retained fallback. Examples belong only to the development Examples aggregate.

The statements below give proposed public names and mathematical types. All open code namespaces are under `LeanInfoTheory.Shannon`. Display abbreviations `row`, `e`, `G`, `L`, `D` and `d` name expressions in the statements. They add no public objects. No input enumeration, output inhabitant, encoder injectivity, support condition, positive length or positive mean is a prerequisite for the finite error results. Supply positive budgets where a uniform law, a maximum, or a derived fallback needs one.

## Proposed steps and acceptance criteria

### C32.01 — Sent-index error, arbitrary priors and the finite maximum

- **C32.01-ROW** — In `BlockChannelCode`, define `messageErrorProbability c W m : ℝ` as `∑ y, if c.decoder y ≠ m then (row m y).toReal else 0`. Prove `errorProbability_eq_mean_messageErrorProbability` with left side `c.errorProbability W hM` and right side `(1 / (M : ℝ)) * ∑ m, c.messageErrorProbability W m`. Reuse the released `errorProbability_eq_sum`. Check that no equality test compares codewords.
- **C32.01-PRIOR** — Define `errorProbabilityWithPrior c W π` by `decodingErrorProbability (PMF.channelJoint π row) c.decoder`, for any `π : PMF (Fin M)`. Prove `errorProbabilityWithPrior_eq_sum` with right side `∑ m, (π m).toReal * c.messageErrorProbability W m`. Verify the uniform prior gives the released error and `PMF.pure m` gives the row error, using the same code. The released finite Fano sum and `PMF.channelJoint_apply` supply the joint-law calculation. There is no division by a prior atom.
- **C32.01-MAX** — Define `maximalErrorProbability c W hM` as the finite maximum over all `Fin M`. Prove `maximalErrorProbability_le_iff` with right side `∀ m, c.messageErrorProbability W m ≤ b` at any real bound `b`, and `errorProbabilityWithPrior_le_maximalErrorProbability` for every prior. Use nonnegative row masses and `PMF.sum_toReal`. Compile focused consumers exercising row and maximum values in `[0,1]`, uniform and pure specializations, and an unused index. Keep simple sum and range estimates local unless a listed interface needs them.

### C32.02 — Restrict indices and transport the total decoder

- **C32.02-DECODE** — Define `BlockChannelCode.restrictMessages c (i : Fin K ↪ Fin M) (j₀ : Fin K) : BlockChannelCode X Y n K`. Its encoder is `fun j => c.encoder (i j)`. Its decoder inverts `i` on its image and sends every other old decoder output to `j₀`. Prove `restrictMessages_decoder_of_eq` by showing that for every output word `y` and new index `j`, `c.decoder y = i j → (c.restrictMessages i j₀).decoder y = j`. Verify the encoder equation and off-image fallback for every output, including zero-probability outputs. Use `Function.extend` with the constant fallback and the injection's left-inverse equation. The existing source-code construction uses this pattern. [SourceCoding precedent](../../LeanInfoTheory/Shannon/SourceCoding.lean)
- **C32.02-ERROR** — Prove `messageErrorProbability_restrictMessages_le` for every retained label `j`. The old and new encoders transmit the same word, and every new failure for `j` was an old failure for `i j` under that row. In a focused development consumer, set `d = c.restrictMessages i j₀` and prove for arbitrary `π : PMF (Fin K)` that `d.errorProbabilityWithPrior W π ≤ c.errorProbabilityWithPrior W (π.map i)`. Weight the row inequalities by `(π j).toReal` and reindex the old-code sum along the embedding. Exercise a second restriction. Start the four-index fixture here so C32.05 can reuse it.

  On the noiseless code with encoder `(0,1,2,2)` and decoder `(0,1,2)`, embed the new labels `(0,1)` as old labels `(0,3)`. Under a uniform prior on the two new labels, the transported prior has mass `1/2` on each of old labels 0 and 3. Its original-code error is `1/2`; uniform error on all four old labels is `1/4`. With new fallback 0, the restricted row errors are `(0,1)`, giving uniform error `1/2`. With new fallback 1 (old label 3), the restricted row errors are `(0,0)`: sending old label 3 yields symbol 2, whose old decoder label 2 is discarded and redirected to the retained sender. These two restrictions exercise both the prior comparison and strict improvement of a row.

### C32.03 — Count all good indices and select exact budgets

- **C32.03-COUNT** — In the finite owner, prove `BlockChannelCode.half_le_card_filter_messageErrorProbability` with `G = Finset.univ.filter (fun m => c.messageErrorProbability W m ≤ 2 * e)` and conclusion `(M+1)/2 ≤ G.card`. Show in the proof or a permanent consumer that `e = 0` forces every row error to vanish and `G = Finset.univ`. For `e > 0`, bound `2*e * (Gᶜ.card : ℝ)` by the sum of bad row errors, then by the total `(M : ℝ)*e`. Cancel the positive mean and use `G.card + Gᶜ.card = M` to obtain the ceiling bound and `1 ≤ G.card`. Ties at `2*e` are retained. Check odd `M` and singleton budgets.
- **C32.03-EXACT** — Prove `BlockChannelCode.exists_expurgated_restrictions` with the witness order below. The single embedding enumerates the whole good set. For each requested budget the returned code is a restriction of the caller's original code at its original length and channel.

  ```text
  L = G.card
  ∃ (hL : 1 ≤ L) (i : Fin L ↪ Fin M),
    (M+1)/2 ≤ L ∧ (Set.range i = (G : Set (Fin M))) ∧
    ∀ (K : ℕ) (hK : 1 ≤ K) (hKL : K ≤ L),
      ∃ d : BlockChannelCode X Y n K,
        d = c.restrictMessages ((Fin.castLEEmb hKL).trans i) ⟨0,hK⟩ ∧
        d.maximalErrorProbability W hK ≤ 2*e ∧
        ∀ π : PMF (Fin K), d.errorProbabilityWithPrior W π ≤ 2*e
  ```

  Use `G.equivFin.symm` and subtype inclusion to enumerate the original labels. For a requested `K`, take its first `K` labels in that enumeration. The fallback is the new index zero. At `K=L` this retains every good index. A second restriction of the full code also satisfies rowwise monotonicity by C32.02. Compile a caller choosing `d` once, then using it for an arbitrary prior and a point mass. Include a check at `K=1` and one at the full budget. Return the embedding and code identity so a consumer can trace every retained word and formerly correct decision.

### C32.04 — Finite rate loss and transfer of one C31 witness

- **C32.04-RATE** — In `Shannon.CodingRate`, prove `codeRate_sub_log_two_div_le_of_le_two_mul` for `0 < n`, `1 ≤ M`, `M ≤ 2*L`, with conclusion `codeRate n M - Real.log 2 / (n : ℝ) ≤ codeRate n L`. The hypotheses imply `1 ≤ L`. Apply logarithm monotonicity to `M ≤ 2*L`, expand `log (2*L)`, and divide by positive `n`. Apply this to the full retained budget from C32.03. The rate statement for an arbitrary requested `K` would require `M ≤ 2*K`.
- **C32.04-FAMILY** — In `Shannon.OperationalExpurgation`, prove `exists_expurgated_family_of_tendsto_errorProbability`. Take `W,R,M,hM,c` from one C31 witness, and write `eₙ = (c n).errorProbability W (hM n)`. Assume `Tendsto (fun n => eₙ) atTop (nhds 0)` and `∀ δ > 0, ∀ᶠ n in atTop, R-δ ≤ codeRate n (M n)`. The real target enters only in the rate floor. Return one family `L : ℕ → ℕ`, `hL : ∀ n, 1 ≤ L n`, `D : ∀ n, BlockChannelCode X Y n (L n)` with all three properties below.

  1. At every `n`, `((M n) + 1)/2 ≤ L n`, and there exists `iₙ : Fin (L n) ↪ Fin (M n)` whose range is precisely that length's good set and for which `D n = (c n).restrictMessages iₙ ⟨0,hL n⟩`.
  2. At every `n`, `(D n).maximalErrorProbability W (hL n) ≤ 2*eₙ`, and these maxima tend to zero along `atTop`.
  3. For every positive `n`, the loss bound of C32.04-RATE holds between `M n` and `L n`. For every `δ > 0`, eventually `R-δ ≤ codeRate n (L n)`.

  Choose the full code at each length once. Nonnegativity and the twice-mean bound give the maximal-error limit by squeezing. Use the original rate tail at `δ/2` and the positive-length tail where `log 2/n < δ/2`. A permanent caller opens `h : IsAchievableRate W R` once, passes its actual witnesses to this theorem, and specializes two tolerances on the same returned family. C32.05 extends that caller to exact budgets and priors varying with length.

### C32.05 — Permanent collision, boundary and C33 consumers

- **C32.05-COLLISION** — Reuse the length-one four-index fixture from C32.02. Prove that the original row errors in index order are `(0,0,0,1)`, the released uniform error is `1/4` and the actual error under `PMF.pure (3 : Fin 4)` is `1`. At threshold `2*e=1/2`, expurgation retains precisely old labels `{0,1,2}`. Prove that this three-label code has maximal error zero and specialize it at multiple priors. Exercise the generic exact-budget result at a smaller positive budget. At `n=1,M=4,K=1`, verify `codeRate 1 4 - Real.log 2 > codeRate 1 1`. The earlier restriction to `{0,3}` tests the behavior of the general decoder operation, while `{0,1,2}` tests selection by row error.
- **C32.05-BOUNDARY** — For the odd-budget check use the length-one noiseless three-symbol channel with encoder `(2,0,2,1,2)` and decoder sending symbols `(0,1,2)` to old labels `(1,3,4)`. The row errors are `(1,0,1,0,0)`, the mean is `2/5`, and the threshold is `4/5`. Check that the embedding returned by C32.03 has range exactly `{1,3,4}` and retained count `3 = ⌈5/2⌉`. Any enumeration of these three labels satisfies the check. Exercise zero mean with all indices retained, singleton error and maximum zero at arbitrary length, and empty words at `n=0`. At zero length the sole decoder output identifies the one row with error zero, and every other row has error one, giving the released mean `1 - 1/M`. Apply the finite theorem there, including threshold equality at `M=2,e=1/2`. Use positive blocklength for the rate estimates.
- **C32.05-CALLER** — Complete the C33-facing development example using only supported imports. Open one C31 witness and take the full retained family `L,hL,D` from C32.04, with its eventual rate floor and vanishing maximal error. For any supplied `K : ℕ → ℕ`, `hK : ∀ n, 1 ≤ K n` and `hfit : ∀ n, K n ≤ L n`, exhibit one family `d : ∀ n, BlockChannelCode X Y n (K n)`. Define `d n` by restricting `D n` along `Fin.castLEEmb (hfit n)` with fallback `⟨0,hK n⟩`. Select the family before both of the following obligations.

  1. At each `n`, for every `π : PMF (Fin (K n))`, prove
     ```text
     (d n).errorProbabilityWithPrior W π
       ≤ (d n).maximalErrorProbability W (hK n)
       ≤ (D n).maximalErrorProbability W (hL n).
     ```
     Apply the prior-to-maximum bound, rowwise restriction, and the finite maximum characterization. At a supplied length, exercise the same code with a pushforward prior `p.map f` and a point mass.
  2. For every sequence `π : ∀ n, PMF (Fin (K n))`, prove `Tendsto (fun n => (d n).errorProbabilityWithPrior W (π n)) atTop (nhds 0)`. Squeeze the nonnegative errors by the single vanishing sequence of maxima for `D`. This allows a different source-induced prior at every length.

  The rate floor is on `L`. If the source budgets fit only eventually, C33 uses this construction on the fitting tail and handles the exceptional lengths in its own code family. C33 also owns the joint reconstruction bound and the biased-source composition example.
