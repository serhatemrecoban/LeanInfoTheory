## Advisory proof route

1. Convert the identity decoder's reversed inequality test to the coupling
   disagreement event using finite real event sums. Transport that event
   through `Prod.swap`. Both decoder errors then equal the same exact TV.
2. Use both entropy chain rules and nonnegativity to bound each signed
   entropy difference by the corresponding conditional entropy; apply Fano
   twice and `abs_le`. Do not compare two independently selected witnesses.
3. For the scalar cap, use upstream q-ary monotonicity on the closed interval.
   A private `m>=2` cast normalization equates the raw expression with q-ary
   entropy. A short log/rational calculation proves the threshold value.
   Either the upstream decreasing branch or the entropy range handles large
   budgets; both are available. Singleton/empty handling comes first.
4. For each marginal use `PMF.totalVariation_map_le`, then the **budget**
   entropy theorem. Apply the existing algebraic information identities and
   triangle inequalities. Never replace marginal TV in the non-monotone raw
   exact-distance expression without its own range argument. The source-verified
   `Fintype.card_prod` rewrite is a convenient way to normalize joint cardinality;
   an equivalent proof preserving the natural product contract is acceptable.

for Fano's all-cardinality q-ary normalization. This intake considered it and

the exact inequality total over finite PMFs because the compiled proof and
existing Fano need no `m>=2` hypothesis; conventional interpretation at `m>=2`

entropy terms. They need not be optimal or collapse to zero merely because
