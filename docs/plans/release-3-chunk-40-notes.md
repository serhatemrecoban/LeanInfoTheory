## C40.02 — Standalone finite testing

The [replay caller](../../tests/release-3-qualification/FiniteTesting.lean) imports only `LeanInfoTheory.Probability.NeymanPearson`. It extracts witnesses from the two public `IsLeast` results. For arbitrary finite laws P and Q the attainable minima are 1 − TV(P,Q) for the sum of errors and half that value for equal priors. Each witness bounds the loss of every competing randomized test. The calibrated caller chooses a threshold and one common tie weight for every level in the closed unit interval. The same test has the prescribed size and dominates every competitor with size at most that level.

A test value of one means rejection of the null. Size averages the rejection weights under P, power averages them under Q, and miss is one minus power. At level zero the comparison includes all tests with zero null rejection. At level one the always-reject competitor proves that the calibrated witness attains power one. The finite mass comparison gives exact decisions on atoms where one or both laws vanish. For finite PW24 log threshold τ on jointly positive atoms, the Lean parameters are c = exp(−τ) and γ = 1 − λ. The mass rule also allows c = 0, when an atom present only under P lies on the boundary. The existence theorem permits multiple calibrations. [C26 source adaptation](../handoffs/chunk-26.md#mathematical-source-adaptation)

| Laws and threshold | Rejection probabilities | Size | Power | Miss |

| Boolean (false, true). P = (1/2, 1/2), Q = (3/4, 1/4), c = 3/2 | (1/2, 0) | 1/4 | 3/8 | 5/8 |
| Four labels. P = (1/6, 1/3, 1/2, 0), Q = (1/4, 1/2, 1/4, 0), c = 3/2 | (γ, γ, 0, γ). The totals here use γ = 1/2. | 1/4 | 3/8 | 5/8 |
| Three labels. P = δ₀, Q = δ₁, c = 2 | (0, 1, γ) for every γ in [0,1] | 0 | 1 | 0 |

The compiled caller checks that both positive tied atoms use the same γ, and derives the Boolean optimal-power bound for every feasible competitor. The disjoint laws expose the null-only, alternative-only, and common-null decisions in that order. The common-null decision has zero weight under both laws.

## C40.03 — Coding through source–channel separation

### From a sampled book to one deterministic code

The sent word and its output have the joint law J. A different label and the sent output have the independent law Q after averaging over the sampled book. A fixed book can contain duplicate words. The public one-shot theorem selects a book in the sampling support and fixes its total deterministic decoder at the supplied blocklength, message count and channel. Its conclusion bounds the released uniform-message error. The decoder chooses the first passing label and uses label zero when none pass.

The global test is the strict mass inequality exp(t) Q(z) < J(z). Ties belong to the miss. Comparing the log information density to t requires joint support. For a uniform four-symbol input on the noiseless one-use channel, an off-diagonal pair has Q mass 1/16 and J mass zero. It fails the global test even at t = −1. At t = log 4 the positive diagonal atoms tie. At t = log 3 the diagonal passes, the true miss is zero, and the independent pass probability is 1/4. With two messages the same selected code has error at most 1/4 from the event bound and at most 1/3 from the exponential bound. Enumerating the 16 books gives mean error 1/8. A duplicate pair gives error 1/2 and a single-message code has error zero. The separately built permanent ternary example gives bounds 11/32 and 2/5. [One-shot caller](../../tests/release-3-qualification/OneShot.lean) · [C30 source adaptation](../handoffs/chunk-30.md)

### One family before all rate tolerances

Given 0 ≤ R < C, choose one input law p and one slope R < s < I(p;W). At length n, the one-shot input is iid(p,n), the channel acts independently on the n coordinates, the message count is roundedMessageSize(n,R), and the threshold is n s. The miss in the one-shot inequality is the same complemented event as in iid concentration. The ceiling lies in [exp(nR), exp(nR) + 1). At positive n and nonnegative R the rounded rate lies between R and R + log(2)/n. Rounding bounds the competing term by exp(−n(s−R)), so both terms tend to zero. The selected code family has positive budgets at every length before any rate tolerance is chosen. A separate one-message family has zero error and zero rate at every length, including at zero capacity. The weak converse applies to any achievable rate, and capacity is the least upper bound.

Full expurgation retains every label with error at most twice the original uniform mean, including ties. Its budget L satisfies (M + 1) / 2 ≤ L with natural-number division. The resulting family has vanishing maximal error. At positive n its rate loses at most log(2)/n from the original budget. For any fitting positive K one can also select a restriction before specifying the prior, so a single restricted code controls all priors on its K labels. The rate-loss estimate uses the size of the full retained set. [Rate and expurgation caller](../../tests/release-3-qualification/Rate.lean) · [C32 handoff](../handoffs/chunk-32.md)

### Reconstruction under the induced message prior

Finite composition adds the source error and channel error under the pushforward of the source law by its encoder. In the permanent four-message collision, the source always sends label 3 and the noiseless channel code maps labels to (0,1,2,2). The source error is zero, the uniform channel error is 1/4, and both the induced-prior channel error and actual reconstruction error are one. Substituting the uniform error would give the false inequality 1 ≤ 1/4. [Permanent example](../../LeanInfoTheory/Examples/SourceChannelCode.lean) · [Direct caller](../../tests/release-3-qualification/SeparationDirect.lean)

The source budget eventually fits inside the full retained channel budget. The code families are total, with definite encoder and decoder choices at length zero and any earlier nonfitting lengths. Repeating one fair bit twice gives a diagonal input with fair marginals. The finite Fano bound applies undivided at n = 0 and reduces to 0 ≤ log 2. The two-owner caller sends the direct theorem’s very same families and vanishing-error proof through the converse.
