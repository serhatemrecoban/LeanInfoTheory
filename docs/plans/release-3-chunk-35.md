## Contract

A binary code assigns one finite Boolean list to each original label. For a given assignment, the prefix condition below says that a prefix relation between two assigned words forces equality of their labels. Since a word prefixes itself, this also gives injectivity. Conversely, an injective assignment whose distinct image words never prefix one another satisfies the condition. The length is the number of binary digits. The Kraft sum is real and dimensionless.

Propose three declarations in `LeanInfoTheory.Shannon`, all in the focused owner `LeanInfoTheory.Shannon.PrefixCode`. These are proposed signatures and a defining equation.

```lean
variable {S : Type u}

def IsBinaryPrefixCode (c : S → List Bool) : Prop :=
  ∀ ⦃a b : S⦄, List.IsPrefix (c a) (c b) → a = b

theorem IsBinaryPrefixCode.kraft_sum_le_one [Fintype S] {c : S → List Bool}
    (hc : IsBinaryPrefixCode c) :
    (∑ a : S, (1 / 2 : ℝ) ^ (c a).length) ≤ 1

theorem exists_isBinaryPrefixCode_of_kraft_sum_le_one [Fintype S]
    (ℓ : S → ℕ) (h : (∑ a : S, (1 / 2 : ℝ) ^ ℓ a) ≤ 1) :
    ∃ c : S → List Bool, IsBinaryPrefixCode c ∧ ∀ a, (c a).length = ℓ a
```

The predicate needs no finiteness instance. The two theorems expose finite sums. Both apply to an empty alphabet, zero lengths, repeated lengths, and strict slack in the budget whenever their displayed hypotheses hold. The public contracts require neither an order nor a decidable equality instance on the labels. Realization returns an assignment on the original type, with a pointwise length proof a caller can substitute into a sum. Classical finite choices are acceptable. Only existence is specified.

## C35.02 — Realize admissible lengths on their original labels

For `Finset.induction_on_max_value ℓ`, use the following motive for a finite set `t` of original labels. The restricted budget is a premise of the induction hypothesis. The assignment is total on `S`, with both obligations restricted to `t`.

```lean
(∑ x ∈ t, (1 / 2 : ℝ) ^ ℓ x) ≤ 1 →
  ∃ c : S → List Bool,
    (∀ x ∈ t, (c x).length = ℓ x) ∧
    (∀ x ∈ t, ∀ y ∈ t, List.IsPrefix (c x) (c y) → x = y)
```

- **C35.02-SPACE** — Let `a ∉ t` be the new label of maximal length `d = ℓ a`. Given the budget on `insert a t` and an assignment on `t` of the prescribed lengths, choose an actual depth-`d` word with no old word as a prefix. Use `List.Vector Bool d` for the candidate leaves. For an old word `w` of length `k ≤ d`, form its forbidden set by appending each `List.Vector Bool (d − k)` suffix to `w`, using `k + (d − k) = d`. Before counting, show that a leaf `v` belongs to this image exactly when `List.IsPrefix w v.toList`. In the prefix direction, decompose `v.toList = w ++ s` and use lengths to obtain `s.length = d − k`. In the image direction, the appended suffix witnesses the prefix. For `k = d` the only suffix is empty.

  Multiplying the budget by `2^d` and transferring to natural numbers gives `1 + ∑ x ∈ t, 2^(d−ℓ x) ≤ 2^d`. By `card_vector` there are `2^d` candidate leaves. Each forbidden image has at most `2^(d−k)` members. `Finset.card_biUnion_le` bounds the union by their sum, which is strictly smaller than the number of leaves. Choose a leaf outside the union and use the membership equivalence to rule out every old prefix.
- **C35.02-ASSIGN** — Deliver the displayed existence theorem. Start at `∅` with the constant empty-word assignment, whose restricted obligations are vacuous. At `insert a t`, drop the nonnegative new term from the budget and apply the induction hypothesis on `t`. Change only the value at `a` to the word selected in C35.02-SPACE. The previous length equations and prefix implications still hold on `t`. If the new word prefixes an old word, maximality of `d` forces equality of the words, which would place the new leaf in the forbidden set. Apply the motive to `Finset.univ` to obtain the prefix condition and length equation for every original label. Check ties, strict slack and depth zero through the focused import. Keep the auxiliary construction private.
