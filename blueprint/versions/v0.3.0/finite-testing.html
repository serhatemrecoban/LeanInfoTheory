Finite hypothesis testing

How often can a test detect an alternative law if its probability of a false alarm must be exactly one quarter? For two specified laws on a finite alphabet, the Neyman–Pearson theorem answers the same question at every level from zero to one. Its proof has two parts. First, a threshold test maximizes power at its own size. Then a choice of threshold and randomization gives that test the requested size.

Size, power and a two-outcome test

Let p(x) be the probability of observing x under the null law and q(x) its probability under the alternative. In Lean these laws are P0 and P1. A randomized test assigns each observation a number f(x) in [0, 1], the probability of rejecting the null after seeing that observation. This definition works on any observation type. A finite alphabet lets us evaluate the test by summing its rejection probabilities under each law. Test definition · Lean source

size(f) = ∑x p(x) f(x)
power(f) = ∑x q(x) f(x)

The size is the type I error. The power is the probability of detecting the alternative. The type II error, or miss probability, is one minus the power. Size (source), power (source), type II error (source).

Why a threshold test is optimal

Choose a nonnegative threshold c and a rejection probability γ in [0, 1]. The threshold test f compares the alternative atom mass with c times the null atom mass.

f(x) = 1 if q(x) > c p(x)
f(x) = 0 if q(x) < c p(x)
f(x) = γ if q(x) = c p(x)

Every tie uses the same γ. An observation with zero null mass and positive alternative mass lies above the threshold, so the test always rejects there at zero cost in size. If both masses vanish, the test uses γ and that observation contributes zero to both sums. Threshold test (source) · Pointwise rule (source)

Fixed-threshold comparison. On a finite alphabet, every randomized test g with size(g) ≤ size(f) has power(g) ≤ power(f). This holds for each choice of c and γ, including c = 0. Theorem in the API · Lean proof

  1. At each observation, (g − f)(q − c p) ≤ 0. Above the threshold f = 1 and g ≤ 1. Below it f = 0 and g ≥ 0. On a tie the second factor is zero.
  2. Sum the pointwise inequalities. This gives power(g) − power(f) ≤ c (size(g) − size(f)). The right-hand side is nonpositive by the size hypothesis and c ≥ 0.

In the table, the two alternative-to-null mass ratios are 3/2 and 1/2. Take c = 3/2 and γ = 1/2. The first observation is a tie and the second is below threshold. The comparison now shows that even a randomized competitor of size at most 1/4 cannot exceed power 3/8.

How to attain the prescribed size

Finite Neyman–Pearson theorem. For two laws on a finite observation alphabet and each a in [0, 1], there exist a nonnegative threshold c and a common tie probability γ such that the resulting test has size exactly a. Its power is at least that of every randomized test of size at most a. The same choice works against all competitors. Exact-size theorem in the API · Lean proof

To select the threshold, restrict attention to observations with positive null mass. On this support the ratio r(x) = q(x)/p(x) is defined. For a realized ratio c, write U for the null mass strictly above it and B for the null mass tied at it. The threshold test spends U + γB of its size budget.

  1. Choose the largest realized ratio whose weak upper tail, U + B, is at least a. At the smallest realized ratio this tail has null mass one. If there is a next higher ratio, its weak upper tail is exactly U and falls below a. Otherwise U is zero. Thus U ≤ a ≤ U + B. Finite threshold selection in Lean
  2. The threshold is realized on positive null support, so B > 0. Set γ = (a − U)/B. It lies in [0, 1] and gives size a. Apply the fixed-threshold comparison to this test to obtain the power bound.

The closed interval includes sizes zero and one. Even at size zero the test can detect observations found only under the alternative. Both laws may have different supports. The theorem provides an optimal test for each level, without requiring the threshold or the optimizer to be unique.
